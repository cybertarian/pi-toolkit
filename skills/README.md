# skills/

Agent skills: a `SKILL.md` router plus `references/` (deep material read only
when needed) and `assets/` (shipped code/config). Install by copying the
directory into `~/.pi/agent/skills/` (user) or a project's skills directory.

| Component | What it does | Status |
|---|---|---|
| [bmad-loop-pi](bmad-loop-pi/) | Set up [bmad-loop](https://github.com/bmad-code-org/bmad-loop) to drive pi as its coding CLI (out-of-tree `pi` adapter) | ready |
